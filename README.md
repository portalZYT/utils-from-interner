# utils-from-interner
This is a collection of useful tools available on the internet, including a wide variety of tool projects.
### 1、pdynamic-questionary-form
问卷项目，支持拖拽控件，支持多种题型，支持数据导出
### 2、ionic3-open-pdf
Ionic3查看PDF文件
### 3、ipa-inhouse-download
iOS通itms-services://协议安装ipa，省去https环境的搭建
### 4、zeptoAppjs
这是一个用AppJs做控制器，用zepto轻量级框架结合LocalStorage本地存储编写的一个事务管理App
用cordovad打包成apk可执行文件
### 5、pdf-signaturer
`PDF` 在线签名的简单实现
